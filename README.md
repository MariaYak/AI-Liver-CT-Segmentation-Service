AI-сервис сегментации КТ-снимков печени

Цель: разработать сервис для автоматической сегментации печени на КТ-снимках: дообучить модель машинного обучения на данных реальной клиники и интегрировать её в удобный веб-сервис для работы медицинских специалистов.

Моя роль: продуктовая и аналитическая проработка проекта: постановка проблемы, анализ целевой аудитории и её потребностей, создание портрета пользователя, анализ аналогов и конкурентов, определение ключевых функций MVP и направлений дальнейшего развития продукта. 

Инструменты: анализ целевой аудитории, Persona, конкурентный анализ, MVP, Kanban, Product Backlog, анализ технических вариантов реализации и проектирование пользовательского сценария медицинского сервиса.

Результат: разработана концепция веб-сервиса с моделью машинного обучения для автоматического выделения контура печени на КТ-снимках.
